# 01. 升降级与席位流转机制

## 目标

将 LPL 的战队竞争门槛从“单赛季短期表现”转为“长期运营 + 选手培养 + 赛季稳定性”的组合模型，避免弱队和低质量运营长期拖累联赛整体竞争力。

## 核心机制

1. 赛季积分制
   - 常规赛结束后，前 8 名直接锁定下赛季席位。
   - 第 9-10 名进入保级附加赛。
   - 第 11-12 名直接进入降级区间，若运营预算低于阈值，则需额外接受联盟审查。

2. 保级附加赛
   - 由第 9-10 名与次级联赛前 2 名进行双循环对抗。
   - 若最终战队在两轮总胜场中占优，则保留席位；否则席位流转。

3. 席位流转规则
   - 若战队因资金不足或选手流失导致连续两个赛季未完成保级，则其席位优先开放给“青训体系完整、预算可持续”的新晋战队。
   - 新战队若在次级联赛中完成 2 个赛季稳定表现，可直接申请升入主赛区。

## 实施建议

- 将“保级”从单一成绩指标扩展为“成绩 + 运营健康度 + 青训投入”三维评价。
- 对连续两年进入保级附加赛的队伍，要求提交赛季运营报告。
- 对高风险队伍设立“观察期”，减少突然降级对联赛生态的冲击。
