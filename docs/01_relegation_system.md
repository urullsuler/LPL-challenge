# 01. 升降级与席位流转机制

## 目标

将 LPL 的战队竞争门槛从“单赛季短期表现”转为“长期运营 + 选手培养 + 赛季稳定性”的组合模型，避免弱队与低质量运营长期拖累联赛整体竞争力。

## 核心机制

1. 赛季积分制
   - 常规赛结束后，前 8 名直接锁定下赛季席位。
   - 第 9-10 名进入保级附加赛。
   - 第 11-12 名直接进入降级区间，若运营预算低于阈值，则需额外接受联盟审查。

2. 保级附加赛
   - 由第 9-10 名与次级联赛前 2 名进行双循环对抗。
   - 若最终战队在两轮总胜场中占优，则保留席位；否则席位流转。

3. 席位流转规则
   - 若战队因资金不足或选手流失导致连续两个赛季未完成保级，则其席位优先开放给“青训体系完整、预算可持续”的新晋战队。
   - 新战队若在次级联赛中完成 2 个赛季稳定表现，可直接申请升入主赛区。

## 法务与合规对策

为了避免保守派俱乐部和资本方以“违约”“商业协议不明确”为由反对改革，建议把制度设计拆成“阶梯式商业分成 + 书面保障 + 过渡缓冲”三层：

- 阶梯式商业分成：若战队完成保级，则保留其当季商业分成的基础份额；若未完成保级，则保留底部分成，并将多余份额转入联盟缓冲基金。
- 书面保障：联盟与战队签署的席位协议中明确加入“成绩与财务达标条款”，并规定降级或保级附加赛的执行机制。
- 过渡缓冲：对于新晋战队或降级队伍，设置 1 个赛季的补贴与转播分成缓冲期，降低资本突然撤资的冲击。

## 实施建议

- 将“保级”从单一成绩指标扩展为“成绩 + 运营健康度 + 青训投入”三维评价。
- 对连续两年进入保级附加赛的队伍，要求提交赛季运营报告。
- 对高风险队伍设立“观察期”，减少突然降级对联赛生态的冲击。
