# 04. 可落地到项目中的改革模块

## 1. 弹性升降级与保级附加赛

将“席位固化”改为“年度升降级”机制，可以让战队和资本真正感受到生存压力。

- 最后 1 名直接降级
- 倒数第 2 名与次级联赛冠军进行 BO5 保级战
- 降级队伍可保留短期缓冲金，减少资本突然撤资带来的系统性冲击

## 2. 新人选拔与公开选秀

建议将“选秀”从形式化流程升级为“公开、透明、可追踪”的选拔机制。

- 面向 Challenger、高校联赛、路人王赛和高分选手开放报名
- 通过统一测试和实战演练公开展示能力
- 弱队优先选择新人，避免强队长期垄断顶尖人才

## 3. 新秀强制出场规则

可以把“新秀上场率”写成制度化规则，直接纳入联赛考核。

- 每支战队每赛季必须保证一定比例的新秀出场时间
- 若达不到要求，战队将受限于分红、选秀权或薪资帽
- 目标是让战队必须给新人真实比赛机会，而不是只养老将

## 4. CVI 与观察名单

将选手评价从“名气”改成“竞技价值”。

- 设定 CVI 评分区间与低效选手阈值
- 连续两个赛季低于阈值的选手进入观察名单
- 对低效老将实施限薪、合同年限限制或转会限制

## 5. 三级联赛与外部挑战者通道

把联赛体系扩展为“顶级联赛 + 挑战者联赛 + 城市/高校联赛”的开放链路。

- 让外部战队和独立资本更容易进入职业体系
- 提高底层竞争强度，避免职业联赛流于“养老院”

## 项目建议

这些模块非常适合在当前仓库中继续拓展为以下内容：

- 规则配置文件：描述不同模块的阈值、流程和奖励/惩罚
- 面向数据分析的评分模型：用于模拟 CVI 和保级风险
- 看板页面：将不同改革模块可视化呈现给观众和评审
